# 求职空间

一个本地优先的个人求职管理网页，适合记录校招岗位、面试经历和求职日程。界面运行在自己的电脑上，不需要账号，也不会把求职数据上传到云端。

## Windows 快速开始

1. 安装 [Node.js 20 或更高版本](https://nodejs.org/)。
2. 下载并解压本项目，或使用 Git 克隆。
3. 双击 `安装并启动求职空间.vbs`。

首次运行会自动安装依赖、在后台启动本地服务并打开浏览器。安装完成后，求职空间会在每次登录 Windows 时静默启动，日常直接访问：

```text
http://127.0.0.1:4455
```

项目文件夹移动到新位置后，请重新双击一次 `安装并启动求职空间.vbs`，以更新开机启动路径。

如果不想让它登录后自动运行，双击 `取消开机常驻.vbs`。这只会移除启动项，不会删除项目或求职数据。

## 命令行启动

Windows、macOS 和 Linux 都可以使用：

```bash
npm install
npm start
```

`npm start` 会启动服务并自动打开浏览器。Windows 也可以双击 `启动求职空间.cmd` 在前台运行；关闭它的终端窗口即停止服务。

## 功能

- 以公司为单位管理多个校招岗位、进展、地点、薪资、链接和备注
- 公司归档、状态筛选、搜索及拖动排序
- 按岗位沉淀多轮面试记录，并与校招进程双向跳转
- 月历式求职日程，支持具体时间的面试和跨日期时间段
- 首页概览、最近再看及数据统计
- JSON 数据导入、导出和恢复

## 数据与隐私

求职数据保存在项目目录中的 `workspace-data.json`，并在 `workspace-data.json.bak` 中保留最近一次备份；浏览器本地缓存作为备用。这些文件已被 Git 忽略，不会随代码提交到 GitHub。

每位使用者都会拥有独立的本地数据。升级代码前仍建议先从“数据管理”导出一份 JSON 备份。

固定地址为 `http://127.0.0.1:4455`。不同域名或端口的浏览器缓存彼此独立，请保持使用这个地址。
